快速开始

  1. 在「AI 模型」中选择厂商与套餐，填入 API Key 并保存；密钥会加密存入本机 SQLite。
  2. 点击「获取模型列表」拉取官方模型，随后在「模型名称」下拉中选择；支持图像输入的模型会标注 可识图。
  3. 点击「保存并测试」发送一次真实请求，确认接口与密钥可用。
  4. 首次体验可用 mock 后端；未配置模型时自动使用内置演示策略。
  5. 在「设置 → MCP 资源」点击「检测并修复资源」，系统会自动下载并构建缺失的桌面组件。
